---
description: Create a new React component with standard structure
---

1. Ask the user for the component name (e.g., "Button", "Modal")

2. Create the component file in `src/components/{ComponentName}.tsx`

3. Use this structure:
   - TypeScript interface for props at the top
   - Functional component with named export
   - Tailwind classes for styling

4. If component needs state, add appropriate hooks

5. Show the created file for review
